# DIA 2
## 200
1. Traduccion humana: la solicutud salio bien y el servidor entrego la pagina solicitada
2. Situacion cotidiana:  Es como pedir un libro en una biblioteca y que el encargado te lo entregue correctamente
3. Ejemplo de internet: Al entrar a una pagina web que funciona correctamente el servidor responde con 200 ok
4. ¿Que podria hacer la persona usuaria?: Puede continuar navegando normalmente por la pagina
## 301
1. Traduccion humana: La pagina se cambio permanentemente a otra direccion 
2. Situacion cotidiana: Es como llegar a una tienda y encontrar un aviso que dice que se mudo a otra direccion
3. Ejemplo de internet: Una pagina antigua redirige automaticamente hacia una nueva URL
4. ¿Que podria hacer la persona usuaria?: Seguir el enlace o esperar a que el navegador le redirija automaticamente
## 404
1. Traducion humana: El servidor no encuentra la pagina que se le solicito
2. Situacion cotidiana: Es como buscar una direccion que ya no existe o esta mal escrita
3. Ejemplo e internet: Escribir una URL incorrecta o entrar a un enlace de una pagina que fue eliminada
4. ¿Que podria hacer la persona usuaria?: Revisar la direccion, regresar a la pagina principal o buscar nuevamente la informacion
## 500
1. Traducion humana: Ocurrio un problema interno en el servidor
2. Situacion cotidiana: Es como ir a una tienda que esta abierta, pero el sistema de atencion dejo de funcionar
3. Ejemplo de internet: Intentar abrir una pagina y recibir el mensaje
4. ¿Que podria hacer la persona usuaria?: Esperar unos minutos y volver  a intentar entrar. Si continua, puede informar el problema al administrador del sitio
