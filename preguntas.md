# DIA 11
## ¿Que metodo y URL usa la peticion.?
1. la peticion usa un metodo como HTTP como GENT o POST y una URL que indica el recurso de la API al que se esta accediendo.

## ¿Que significa el codigo de estado.?
2. indica el resultado de la peticion, por ejemplo: 200 significa que fue exitosa, 404 que no se encontro el recurso y 500 ocurrio un error en el servicio.

## ¿Que ocurre sin conexion.?
3. la peticicion no puede llegar al servicio, por lo que normalmente nose recibe un codigo HTTP el navegador muestra error de red.

## ¿la API permite este uso.? ¿*tiene limites*?
4. depende de las reglas de la API puede tener limites de solicitudes, restricciones de auteticacion o limites de uso.
