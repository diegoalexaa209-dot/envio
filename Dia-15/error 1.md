## error 1
* # campo vacio
Descripcion: 
El formulario permite enviar los datos aunque un campo este vacio 

* Pasos para reproducirlo:

1. abrir la pagina.
2. dejar un campo vacio.
3. presionar el boton enviar.
4. observar el resultado 

* Resultado esperando:
Deberia aparecer un mensaje indicnado que falta completar elm campo 

* Resultado obtenido:
El formulario se envia aunque el campo este vacio.
