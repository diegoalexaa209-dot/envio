SIGNIFICADO DE FLEX.CSS

¿ QUE ES FLEX.CSS ?

Es una herramienta de diseño web pensada para resolver el problema mas común de una página como acomodor y aliniar los elementos de forma ordenada y adaptable, fue este diseño es es originalmente para maquetar documentos de texto con imagenes no para construir apps web ni interfases complejas

¿PARA QUE SIRVE?

Sirve para organizar, aliniar y distribuir el espacio entre los elementos dentro de un contenedor de forma rapida, eficiente y adaptable a cualquier tamaño de pantalla

- Permite que los elementos se adapten automaticamente a tablet, celulares o computadoras.

- Facilita centrar elementos tanto de forma vertical como horinzontal con pocas lineas de código

- organiza los elementos en una sola direccion a la vez ya sea una vez en fila (horinzontal) o en una columna (Vertical)

CODIGOS Y FUNCIONES

1. (display: flex;) Sirve para activar el contenido flexible

2. (flex-direction: column o row;) Cambia el eje principal de horizontal (fila) a vertical (columna).

3. (justify-content:) Alinea los elementos a lo largo de la fila (horizontalmente). Valores comunes: flex-start (inicio), center (centro), flex-end (final), o space-between (espacio entre ellos)
