¿ QUE SIGNIFICA GRID ?

¿QUE ES GRID.CSS?

es una herramienta nativa de los navegadores que sirve para dividir una pantalla web en filas y columnas, como si fuera una tabla de Excel o un tablero de ajedrez, para poder acomodar los elementos fácilmente.

PARA QUE SIRVE?

Sirve para diseñar la estructura de una página web (por ejemplo: poner el menú arriba, el contenido a la izquierda y una barra lateral a la derecha) sin que las cosas se desacomoden.

- Facilita la creación de interfaces responsivas y estructuras complejas (como tableros o portafolios) con solo un par de líneas de CSS en el contenedor padre (display: grid)
